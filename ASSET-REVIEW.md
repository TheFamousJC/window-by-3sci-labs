Window is based on God's Eye View by Bilawal Sidhu. The original LICENSE is
preserved verbatim. The source code is MIT. The separate terms below apply to
their respective assets. The 3Sci Labs logo identifies this distribution.
Permission under the source license does not imply permission to use the
3Sci Labs brand for an unrelated distribution.

Runtime map tiles, live feeds, and provider credentials are separate from the
bundled assets. Review [DATA_SOURCES.md](DATA_SOURCES.md) and each provider's
terms before operating a public instance. The original provider documentation
covers more integrations and packs than this distribution includes.

Publish from the clean source export as the initial commit of a fresh public
repository. The local baseline history contains the original bundled files.
